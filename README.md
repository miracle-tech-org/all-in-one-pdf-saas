# Inkline — All-in-one PDF SaaS

A full-featured PDF SaaS frontend built with **React + Vite + TypeScript**. All tools, templates, workflows, files, and blog content are **mock data**.

Mirrors the product breadth of the Northline Realty portfolio platform: discovery, spatial browsing, decision tools, trust content, and account flows — adapted for PDF workflows.

## Features

- Home hero search and featured tools
- Advanced tool catalog & filters
- Tool detail pages (mock upload workspace, inquiry, related tools)
- Studio visual tool explorer (map-style)
- Favorites and side-by-side compare (localStorage)
- Template library & detail pages
- Industry workflow playbooks
- PDF size / page estimator
- Insights blog
- Mock auth, workspace dashboard, and contact form

## Quick start

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (usually `http://localhost:3000`).

## Scripts

| Command           | Description                  |
| ----------------- | ---------------------------- |
| `npm run dev`     | Start Vite dev server        |
| `npm run build`   | Typecheck + production build |
| `npm run preview` | Preview production build     |

## Stack

- React 19
- Vite
- TypeScript
